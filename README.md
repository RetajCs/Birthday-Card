Birthday Card

A small web card built with HTML and CSS, created as a hands-on exercise in CSS composition, custom shapes, typography, and responsive styling.

Overview

This project recreates a birthday card using HTML elements and CSS rather than image-based artwork. The heart shape is assembled from CSS shapes and positioned elements, with custom typography layered over the design.

What it demonstrates

* HTML page structure
* CSS positioning and composition
* Custom shapes built with CSS
* Typography and Google Fonts
* Responsive adjustments for smaller screens
* Iterative visual experimentation

Technologies

* HTML
* CSS
* Google Fonts
